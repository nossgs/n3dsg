# Current prototype

Goal: a photorealistic, first-person, player-directed survival world after collapse, with realistic distances and fictional believable geography.

This update reorganizes terrain, vegetation, structures, lighting and player code while revising tree proportions and branching. Geometric foliage remains a placeholder, not the final visual target. No external assets are included.

The local region is 384 meters across. Ground-following samples the displayed terrain's triangles. Collisions remain limited to the shelter and nearby tree trunks. Rocks and distant trees are noncolliding. There is no chunk streaming yet.

Next considerations: licensed texture/model assets, performance comparisons, surface detail, and deterministic region/chunk planning. Do not confuse visual prototype quality with the photorealistic end goal.
